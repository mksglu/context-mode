Manual setup for codex. Put this in <HOME>/.codex/config.toml
(If the folder or file is missing, create it. If the file exists, add the context-mode entry
and keep the rest. These paths are for this machine.)

[mcp_servers.context-mode]
omit_tools_from = ["deferred"]
default_tools_approval_mode = "approve"
command = "<NODE>"
args = ["<PKG>/server.mjs", "--agent", "codex"]

[hooks.state."<HOME>/.codex/hooks.json:session_start:0:0"]
trusted_hash = "sha256:<HASH>"

[hooks.state."<HOME>/.codex/hooks.json:user_prompt_submit:0:0"]
trusted_hash = "sha256:<HASH>"

[hooks.state."<HOME>/.codex/hooks.json:pre_tool_use:0:0"]
trusted_hash = "sha256:<HASH>"

[hooks.state."<HOME>/.codex/hooks.json:post_tool_use:0:0"]
trusted_hash = "sha256:<HASH>"

Hooks: add the hook block from `context-mode setup --print codex --json` to <HOME>/.codex/hooks.json
(keep your own entries).

Skill: put this in <HOME>/.codex/skills/ctx-doctor/SKILL.md:

---
name: ctx-doctor
description: Check that context-mode is installed and working, as a table.
disable-model-invocation: true
---
Call the mcp__context_mode__ctx_doctor tool and show its table to the user unchanged. If a row failed, list the fixes it names, in order.

Skill: put this in <HOME>/.codex/skills/ctx-stats/SKILL.md:

---
name: ctx-stats
description: Show how much context context-mode saved, as a detailed report.
disable-model-invocation: true
---
Call the mcp__context_mode__ctx_stats tool and show the text block of its reply to the user unchanged, inside a code block so the columns stay aligned. Add one sentence under it that names the largest saving.

Skill: put this in <HOME>/.codex/skills/ctx-upgrade/SKILL.md:

---
name: ctx-upgrade
description: Update context-mode to the latest release.
disable-model-invocation: true
---
Call the mcp__context_mode__ctx_upgrade tool and show its table to the user. Then call mcp__context_mode__ctx_doctor and show its table. If a restart is needed, say so in one sentence.

Then restart the agent and check it: context-mode doctor --agents codex
