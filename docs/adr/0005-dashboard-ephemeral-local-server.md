# ADR 0005 — Local dashboard is an ephemeral read-only server

- **Status**: Accepted
- **Date**: 2026-10-04

## Context

`context-mode dashboard` visualizes the user's local SQLite data. An earlier
local dashboard for ctx_insight was removed in `11b8b58`: it kept a persistent
`insight-cache/` and a long-lived server, which conflicted with the pivot to
the hosted Insight product and left stale processes that upgrades had to
sweep.

## Decision

The dashboard runs as an ephemeral Node HTTP server bound to 127.0.0.1 on a
random port, alive only while the CLI process runs. It opens every SQLite file
read-only (the analytics module already does), holds no cache, writes nothing,
and dies with Ctrl+C. Updates reach the browser via Server-Sent Events after a
file-mtime digest poll; there is no websocket layer and no new runtime
dependency. The page is vanilla JS with precompiled Tailwind (regenerated by
`npm run tailwind`), not React/Vue, because the repo ships esbuild-bundled
Node code with no frontend toolchain and a read-only report needs no state
reconciliation.

## Consequences

- Upgrade sweeps never see dashboard state because none persists.
- WAL writers (the plugin itself) are unaffected: readers never take write locks.
- Class changes in `src/dashboard/ui.ts` require `npm run tailwind` (wired into `npm run build`) or styles silently miss.
